Column reference

All columns are optional (matched case-insensitively, ignoring spaces/underscores/hyphens). Missing marker columns are treated as not-measured for every row.

  • Marker columns: CD62L, CCR7, CD45RA, CD45RO, CD95, CD69, CD25, PD1, TOX, TCF1, SLAMF6, TIM3, CD101 — values + / - / blank
  • Metadata columns: label, location, lineage, function, migration_evidence (B/W/R), migration_evidence_note, differentiation_override, differentiation_override_note, antigen_status (+/0/blank), antigen_note
